# 大卖智聘产品命名与文案对齐规范

**状态：已确认**

**生效日期：2026-07-29**

**适用范围：** `hr.greatsellai.net` 官网、注册与登录入口、搜索与社交分享信息、销售与市场物料。

## 1. 命名架构

| 层级 | 标准写法 | 使用说明 |
| --- | --- | --- |
| 母品牌 | 大卖数智（GreatSell AI） | 用于 Logo、公司与品牌背书。 |
| 产品名 | 大卖智聘 | 面向客户时的简洁产品名称。 |
| 产品完整名称 | 大卖智聘｜AI 招聘决策工作台 | 首次介绍、官网首屏、社交分享等需要同时说明产品与品类的场景。 |
| 品类说明 | AI 招聘决策工作台 | 用于解释产品定位，不替代产品名。 |
| 固定 Slogan | 让每一次招聘决策，都拥有AI驱动的判断能力。 | 官网首页的唯一固定 Slogan，不改写、不拆分。 |

## 2. 使用规则

- **Logo 与品牌背书：** 使用“大卖数智”，不把产品名嵌入 Logo。
- **官网首屏与核心入口：** 使用“大卖智聘｜AI 招聘决策工作台”。
- **SEO 页面标题：** 使用“大卖智聘｜AI 简历筛选与招聘决策工作台｜大卖数智”，兼顾产品名、用户搜索意图与母品牌。
- **正文第一次出现：** 优先写“**大卖智聘**”，后续可用“系统”“工作台”指代，避免重复堆叠全称。
- **注册、登录及产品内说明：** 在需要面向客户说明产品时使用“大卖智聘”；内部代码、接口和历史技术文档可保留既有技术名称，不为改名制造无关变更。
- **能力表述：** 始终说明 AI 提供依据、总结和辅助判断；候选人是否推进仍由招聘团队决定。

## 4. 不使用的写法

- “大卖数智 AI 招聘工作台”：混淆母品牌与产品名。
- “大卖 AI 智聘”：名称冗长，且“AI”“智”语义重复。
- “AI 选人系统”“招聘大脑”“人才决策引擎”：容易暗示系统自动作出录用或淘汰决定，与产品边界不符。

## 5. 发布前检查

每次新增或修改客户可见内容时，确认：

1. Logo 和品牌背书使用“大卖数智”；
2. 产品名称使用“大卖智聘”；
3. 需要解释定位时补充“AI 招聘决策工作台”；
4. SEO、Open Graph、社交分享和注册入口与官网首屏一致；
5. 不夸大 AI 的自主决策能力，并保留“HR 最终决定”的产品边界。
